## 🔍 Markdown Ka Basic Structure (Aasan Table)

| Kya Chahiye | Kaise Likhein |
|---|---|
| **Bara Heading** | `# Heading 1` |
| **Chhota Heading** | `## Heading 2` |
| **Aur Chhota** | `### Heading 3` |
| **Bold** | `**text**` |
| **Italic** | `*text*` |
| **Numbered List** | `1. Item` |
| **Bullet List** | `- Item` |
| **Code (inline)** | `` `code` `` |
| **Code Block** | ` ``` ` line ke pehle aur baad |
| **Checkmark** | `✅` |
| **Diamond** | `◆` |
| **Pin** | `📌` |
| **Warning** | `⚠️` |

## 🎨 GitHub Par Aise Dikhega

Jab aap GitHub par Markdown file kholenge, to ye **automatically** aise render hoga:

> ## ◆ Step 3: Boot the VM
> 
> 1. Start the VM
> 2. Open a terminal (Linux) or Disk Management (Windows)
> 3. Run the following command to check the new disk:
> 
> ```
> lsblk
> ```
> 
> **📌 Output Example:**
> 
> ```
> NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
> sda      8:0    0   50G  0 disk /
> vdb      8:16   0   20G  0 disk
> ```
> 
> ✅ **New disk (`vdb`) is detected.**

## 🚀 Ab Aap Kya Karein

Aapki repository `azure-powershell-scripts` mein:

**Step 1:** Repository kholiye

**Step 2:** `Add file` → `Create new file`

**Step 3:** File name: **`VM migration disk copy script/README.md`**

**Step 4:** Upar wala Markdown code paste karein (apni script ke hisaab se badal kar)

**Step 5:** `Commit new file`

Bas! Ab GitHub par wo folder kholein to sundar documentation dikhegi. ✨

---

## 💡 Ek Zaroori Baat

GitHub par documentation ke liye hamesha **`.md`** (Markdown) file use karein. `.txt` file use **nahi** karni — kyunke `.txt` mein formatting nahi aati.

| File Type | GitHub Par Dikhega |
|---|---|
| `.md` | ✅ Sundar formatting |
| `.txt` | ❌ Plain text (koi design nahi) |
